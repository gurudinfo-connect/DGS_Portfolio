Flipkart Sales Dashboard

A fully interactive sales-analytics dashboard built inside Excel — no BI tool required — using pivot tables, pivot charts and slicers on top of Flipkart-style retail transaction data.

Microsoft Excel Pivot Tables Slicers
Excel Dashboard (.xlsx)

Overview

This is an Excel-native dashboard rather than a web app — every visual on the page is a pivot chart wired to a set of pivot tables, so a store manager can read total sales, tax, average unit price and quantity sold, then slice the whole page by gender, product line, payment method or customer type without writing a single formula.

The working pivot tables sit on their own sheets so the source numbers stay auditable, while the dashboard sheet pulls everything together into one printable view.

Key Features

KPI Header Cards

Total sales, tax, average unit price and quantity sold, summarised as pivot-table-driven header tiles.

Cross-Filtering Slicers

Gender, product line, payment method and customer-type slicers filter every chart on the sheet at once.

Multi-Chart Layout

Product-sales bar chart, city-vs-customer line chart, city sales bar-in-bar chart and donut/pie splits, all pivot-chart driven.

Pivot-Table Backed

Working pivot tables sit on their own sheets, so every visual updates the moment the source data refreshes.
